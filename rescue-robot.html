Rescue Robot

An autonomous ground robot built to enter collapsed structures and locate survivors before human responders go in, using multi-sensor fusion so no single sensor can trigger a false alarm.

Overview

The Rescue Robot enters structurally unstable spaces too dangerous for human first responders, detecting survivors through thermal signatures, elevated CO2, and acoustic signals: six sensors fused into a single confidence score so no one noisy sensor can trigger a false positive.

Software architecture: dual-loop FreeRTOS

A safety-critical loop (50ms) handles obstacle avoidance, tilt/flip detection, and motor commands, completely independent of a slower detection loop (2000ms) that fuses sensor data, scores confidence, and sends telemetry. Sensor processing never blocks safety response.

Confidence scoring

No single sensor can trigger a confirmed alert on its own. A signal from any one sensor flags a possible survivor and the robot continues investigating; a second, independent sensor agreeing raises that to probable and alerts the operator to prepare entry; a third agreeing confirms the survivor and fires a full alarm with the exact grid location flagged. This escalation is what keeps noisy rubble from generating false alarms.
